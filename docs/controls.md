# 可见控制

以下QQ命令均通过同一发送节流。群管理和自修复开关限已配置主人私聊，不能通过昵称或群消息获得主人权限。

| 入口 | 用途 |
|---|---|
| `/自主空间 状态` | 当前范围等级、运行状态、目标与全设备活动额度 |
| `/自主空间 暂停` / `恢复` | 暂停/恢复当前范围的自主任务；正常被问到的聊天仍可进行 |
| `/自主空间 0` / `1` / `2` / `3` | 0暂停自主工具；1只读；2本范围整理与任务；3获准社交动作 |
| `/自主空间 状态 群号` | 主人查看已启用群的独立自主空间；等级和暂停同样可带群号 |
| `/群内主动 开启 群号` / `关闭 群号` / `状态 群号` | 兴趣插话与群内主动话题开关；被点名的正常回复继续有效 |
| `/群聊 开启 群号` / `关闭 群号` | 只有机器人实际加入的群可启用；关闭保留独立数据 |
| `/群聊 清空 群号` | 清空本群记忆、人格进度、成员关系、学习和自主资料；其他范围不动 |
| `/自修复 状态` / `开启` / `关闭` | 宿主机自修复与看门狗开关，状态返回最近检查时间和服务数量 |
| `/伴随状态` | 当前私聊的模拟状态 |

自然语言也可以明确建立提醒、改变/取消目标、生成资料、搜索或阅读有意提供的附件。工具返回的具体时间、来源和回执才是执行证据。资料分享可选择文字来源卡片或原生生成文件；不同范围的权限会在发送等待结束时再次核对。

全设备每日活动上限由模型在5–8小时内选择；不要求用满。QQ免打扰、发送限额、无人回复暂停、群内插话冷却和资源保护仍优先于活动时长。暂停、降低等级、撤销白名单或关闭群会在等待/工具返回后重新检查，不能因为一个旧请求还在运行就继续向已撤权对象发送。

经验学习：`/学习 状态`、`/学习 内容`、`/学习 效果`、`/学习 回滚 ID`、`/学习 忘记 ID`、`/学习 暂停`、`/学习 清空`。效果是适用的已送达措辞信号，不是人格或情绪评分。详见 [持续学习](self-learning.md)。
