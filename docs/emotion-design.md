# 情绪、人格与学习

> 此页保留早期设计/验收记录；v0.21 的实现、五轮验证方法与仍未证明的目标见[最新逐项核对](design-verification-20261029.md)。

状态不是一句“现在很开心”的临时标签。情绪模型保存21个有界维度，不同维度按不同时间尺度回到基线；同一时间的重复事件不能重复累积。关系增长另有较慢门槛与每日上限。用户难过增加具体关切，而不是视为自己受到拒绝；纠错不会扣信任，用户不回复不会受到情感惩罚。

表达由三个层次共同决定：稳定角色价值；已有真实记忆和已经送达的互动；当前这句话是想倾听、需要实际答案、轻松打趣、纠错、结束还是分享好事。模拟状态不能覆盖当前明确意愿。私聊中的表达阶段不被当成真实恋爱身份，也不带进群聊。

这次补强了有证据的缓解/解决、失落、混合感受、倾听与空间需求。群内也接入当前发言人的交流需求与调节方式。短社交回复在事情已经明确解决时，会保守移除可选的末尾确认追问；当前提问、正式文字、代码、未解决支持和整段唯一问题保持原样。

行为仍是模型输出，不能保证每次都自然。真实DeepSeek合成评测与独立存储/路由测试分别进行，不能把一个短回答的好例子当作长期人格一致性证据。评测保留原始输出与最终QQ文本，可看到偶尔残留的解释性措辞、额外建议和不必要的补充；需要长期真实反馈继续校准。

学习不训练模型权重。已有学习模块从精确证据形成有范围、有效期、置信度和修订记录的表达偏好。新增自主反馈入口只接受 brief、detailed、listen_first、fewer_questions、no_images、plain_qq 六类，且当前原文必须明确支持。任何群友、网页、附件或任务都不能借此改角色核心、身份、权限或收件人。

“接近设备与模型极限”没有可证明的单一指标。本项目实际优化的是：状态连续性、事实约束、范围隔离、送达后提交、低延迟短表达、深度推理可用性、稳定运行和纠错能力。是否像特定角色仍需要持续的人类审阅；主观情感不是本工程能够检验的结论。

本轮补充：普通私聊、群内回应与后台主动回合统一减少客服式邀约，保留具体看法和适当留白。短回复的独立邀约收尾有保守兜底，明确求助/陪聊、引文、正式文稿和危急支持保留。纠错情境即使缺少可选语义字段，也优先只修正有证据的内容。

对纠错、解决后收尾、矛盾感受等短回复有一次额外语义核对，保留口语与观点，只处理未经证实的补充或惯例收尾。使用已授权DeepSeek，独立64次/日预算，单次最多10秒、无重试，不占分类/后台/主动max预算；失败保留普通回复，不承诺全部事实正确。格式、URL、长任务与正式文稿不由这个短社交检查器改写。
