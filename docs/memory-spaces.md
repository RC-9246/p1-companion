# 当前与新对象的独立记忆空间

私聊键是平台、机器人账号和用户账号的确定性哈希，前缀v1；群聊键是平台、机器人账号和群号的确定性哈希，前缀g1；群成员关系再绑定本群键与成员。相同的人在不同群、同一群与私聊、不同机器人下的同一个人，均有独立空间。

公共浏览器为了保持早期接口兼容，对每个群另外派生v1形式的公开工具编号。它不是某人的私聊键，只是同一机器人/群的稳定一一映射。群记忆和自主资料仍使用g1编号；不会读取任何私聊关系。

新增白名单：在AstrBot原生配置启用白名单并添加对应FriendMessage项，保存触发原生管线重载。第一次合规事件或目录同步会按当前机器人/用户派生键，按需建立各模块状态，初始互动次数为0；确认送达才提交真实互动。不能只修改文本文件后假定框架内存中的配置已经重载。

新增群：主人通过群聊开启命令操作；核对机器人真实群目录后记录启用项，按群键建立独立人格种子、情绪、成员关系、记忆与自主空间。上下文包含本群真实发言人、引用、@关系与间隔，不把历史问题当作每次都需要补答的待办。

撤销访问立即阻止新读取/发送；重新授权使用同一个键接续。关闭群保留数据，清空才删除；清空会提高epoch，旧后台回调不能把数据写回来。删除/恢复之间的快照不确定性按保守规则处理，不让旧提醒或已忘记内容静默复活。

验收使用真实AstrBot组件、临时数据库和替身传输：现有四个私聊、一个新增私聊、现有群、新增群逐项走完整请求钩子；另用新进程检查持久化、撤销再授权、关闭再开启、局部清空和旧epoch写入拒绝。测试不创建真实好友、不入真实群、不发送测试QQ。
