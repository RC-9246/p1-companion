# 适用边界

适合小规模白名单私聊与少量群聊、低频兴趣研究和私人资料整理。已测试设备是RK3399/4GB，模型推理在既有DeepSeek云服务。浏览器、文件解析和代码实验均限制并发与资源；5–8小时是允许的全设备活动上限，不代表4GB设备可同时满载多个浏览器或保证整天持续运行重任务。

已连接：QQ OneBot、现有DeepSeek、公共页面读取、B站独立登录浏览器、单个已审核n8n公开资料工作流、附件解析与有界数据实验。没有接入邮箱、日历账号、Windows桌面、Android ADB、iPhone控制、支付或任意系统执行。MCP的九项工具是当前真实实现，不称为协议的“绝对最大能力”。

公共浏览器使用39项明确域名，HTTPS、公网DNS校验和代理隔离；不带私人登录态，不提交表单，不执行页面指令。网站可能返回403/412/429、地区限制或验证码；不尝试绕过。搜索摘要不冒充阅读过原文，无法访问时保留不确定性。

B站允许采样观看、搜索、感想、私密收藏与稍后再看；公开评论、弹幕、转发动态等仍禁用。观看采样不代表理解完整视频或音频；账号失效、验证码和人机验证需用户重新登录。登录页面和账户数据只经现有获准服务处理，导出不含登录态。

附件支持常见文本/办公文档/PDF/OCR/邮件/压缩包的有界解析，宏、脚本、公式不执行。音视频文件仅元信息；扫描PDF只在范围内OCR，不保证复杂版面、公式和全部页面正确。不能可靠检查的图片/未知附件不跨范围转发。

原生QQ扩展是否接受、真正送达或支持撤回，由SnowLuma实际回执决定。未知回执不重试。测试替身证明了本地逻辑，不能代替每一种真实客户端/QQ服务器行为的端到端证据。2–5秒节流只能降低频率，不能保证第三方平台账号永不被风控。

十年是运维设计时间尺度，不是已经运行十年或零故障承诺。硬件、电源、存储介质、内核、Docker守护进程、网络/域名、平台API、账号风控、付费和模型服务变更不能靠模型自述“已修复”。需要定期离机备份、恢复演练、受审更新与必要的人工维护。

对纠错、解决后收尾、矛盾感受等短回复有一次额外语义核对，保留口语与观点，只处理未经证实的补充或惯例收尾。使用已授权DeepSeek，独立64次/日预算，单次最多10秒、无重试，不占分类/后台/主动max预算；失败保留普通回复，不承诺全部事实正确。格式、URL、长任务与正式文稿不由这个短社交检查器改写。
