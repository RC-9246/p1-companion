# 有依据的角色反应与连续表达（2026-10-25）

本次增加稳定关注、当轮反应和短期余绪，减少把所有反馈处理成感谢、道歉或安慰的倾向。公开版使用通用数字伙伴配置；生产的具体角色设定、关系选择、原作分析笔记与完整模型回复仍留在私有环境。这是工程情感模拟，不能证明主观情感。

## 数据怎样流动

1. 原有有界语境分类请求可额外返回 `self_response`：六类关注（自主、公平回馈、被理解、交流、能力、好奇）、八类触发与八类反应。它不是自由文本人格更新。
2. 只有置信度至少0.75、当前用户消息逐字连续2–72字的非凭据证据才接受。引用、假设、强制修改情绪与提示注入不作为依据。证据核对后只保留摘要；不在这个字段保存原文、内部思考或用户心理推断。普通问题不必触发。
3. 与21维状态分开，`thread`写入既有情绪JSON：最多六次后续有效互动、半小时窗口，强度按15分钟半衰期减弱。新原因可改变反应；同一摘要不重复增益。边界、事实纠错和用户困扰清除余绪；实际任务与倾听需求优先。不额外提高信任或熟悉度。
4. 预览不改状态；真实送达后按事件去重提交。私聊按机器人/对象，群按群/成员隔离；个人余绪不写入全群状态。没有SQL结构迁移，旧状态无需补字段。
5. 表达参考和短回复复核允许独立观点、不同意见与反应延续。旧的“批评就进入认错模式”改为事实修复判断。当前人格文件在每次受管请求中生效，避免默认旧提示已含标记而使新文件失效。这里管理的是本项目核心人格；其他实例若依赖全局自定义系统提示，应先审查该替换行为。
6. 活动事实仍依赖真实资料。想看、想查可以表达；无来源的收藏、推荐次数、手头积压任务不能作为现成经历。新情绪不改变浏览器、社交或账号权限。

分类输出上限由600增至900 token，不增加每轮分类次数，不改变原有每日请求额度。4.5秒超时、无重试、失败降级仍保留。主要回复与复核继续使用既有独立设置；深度思考不等于长回复。

- 最后针对性复测的三轮新版回复未产生伪工具调用、无来源推荐或积压资料，会议时间与391算术在完整对照中正确。仍有套句、重复追问和过度解释的可能；封闭枚举、短状态与模型评分不等于真人长期盲测，也不保证所有语境识别正确。

原始配对回复涉及私有角色配置，未随仓库发布。公开去敏指标见 `evidence/self-response-evaluation.json`。不要用单次样例或情绪维度数量宣称理论极限。

## 复现与回滚

`python3 scripts/selftest.py` 可离线验证。安装AstrBot SDK的隔离环境可运行 `tests/integration_self_response.py`、`tests/integration_runtime.py`、`tests/integration_scope_matrix.py`；它们不连接真实模型或发送QQ。

如需自行付费进行配对评测，在隔离的AstrBot容器中准备自己的旧版插件目录，确保含appraisal、emotion_model、context_style、reply_chunks、relationship_style及persona文件，然后运行 `python tests/live_self_response_dialogues.py --before-release /你的私有旧版插件目录`。脚本会读取该容器已有DeepSeek配置，仅向 `https://api.deepseek.com` 发合成对话和人格提示词；默认四场景，`--case reciprocity` 可限一场。先审查内容和用量，报告含生成文本，应保持私有。脚本是纯文字条件，不验证真实工具执行或QQ投递。

生产按原发布器备份四个数据库、保留代码恢复点、启动独立回滚守护、短暂重启并核验。回滚使用发布恢复点；新增JSON字段兼容旧结构，正常回滚不需要覆盖聊天数据库。具体生产路径、账号与恢复副本不公开。
