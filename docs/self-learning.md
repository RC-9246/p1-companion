# 有证据的持续学习

学习由几条互相配合的路径组成，而不是让模型自行修改提示词文件或系统权限：

1. 已实际送达的对话进入当前对象的短期证据账本；明确、无歧义的表达偏好和行为纠错立即落库，不等待后台模型额度。
2. 对较复杂的反馈，用现有 DeepSeek 提取候选；只接受封闭类别、逐字证据和真实消息来源。失败保留旧条目，不靠模型自评分数晋升。
3. 长期事实由 Memoria 的确认流程处理；兴趣随实际讨论、阅读或视频观察缓慢更新；复盘整理连续话题。三者不互相冒充已确认事实。
4. 私聊、群内回应和后台主动回合把当前范围固定词表中的表达偏好和行为经验接入生成设置，原始引文、兴趣、词义和事项更正仍只作不可信资料；大量事项更正不能把这些习惯挤出上下文。
5. 对已明确拒绝的客服式邀约，核对实际送达措辞，保留去重、按版本隔离的观察计数；再次出现时，下轮额外提醒自然收住。该检测不是人格、共情或真实性评分。

## 当前可学内容

表达偏好包括篇幅、建议方式、追问、语气、配图、帮助邀约和独立判断。行为经验包括发言人绑定、真实动作回执、当前话题、核实不确定内容、避免重复建议和接受纠错。还支持明确的兴趣、自述事项更正候选及群内词义。

例：`以后回复简短一些`、`别总给建议，先听我说`、`不需要你总是顺着我讲`、`没必要提“如果你想聊我也可以陪你聊”`。

临时要求、第三人的话、泛化心理猜测、来源不明的引文、权限或身份变更不进入长期表达习惯。引用例句仅有一个很窄的例外：直接要求停止使用特定帮助邀约，且整个原句满足固定模板；不是通用的引号绕过入口。对“他说又弄错了”等第三人反馈，不归因为机器人自身错误。

## 效果和撤销

私聊使用 `/学习 状态`、`/学习 内容`、`/学习 效果`、`/学习 忘记 ID`、`/学习 回滚 ID`、`/学习 暂停` 或 `/学习 清空`。管理员另有 `/群学习 群号 ...`。

新明确偏好替代旧偏好，保留修订。旧异步结果不能越过版本水位覆盖人工审查；过期条目不注入。当前学习条目有效期90天，短期用户证据30天。措辞效果的有效观察窗口30天，新送达核对时清扫过期记录，每范围最多500条，只含作用域、事件引用、学习项版本和检测结果，不另存对话正文。更换规则版本后不把旧版本计数归给新版本；忘记或清空会删除相应效果记录。恢复旧数据库时学习项退回待确认，并清空旧效果记录。

“效果”只计算适用的短回复。明确要求帮助或陪聊、代码、引文、正式文稿、危急支持等不能简单按客服模板扣分。看不到可验证信号的偏好不自动评分。不能凭没有检测到某个句式就宣称对话完全自然。

## 隔离和资源

每个白名单私聊单独保存；群聊的成员偏好按群与成员共同隔离，公共词义另存，需独立发言人证据。新增白名单或群首次使用时延迟创建独立空间。撤权立即阻止继续读取和使用；群友不能改核心人格、账号、白名单或系统权限。

即时学习不调用模型；语义提取单工、每日最多24次，受调用超时、来源检查与撤权复核约束。检索、修订、效果检查在本地 SQLite 完成。不新增外部嵌入目的地，不上传整库。深度思考用于需要权衡的任务，不能用长思考替代证据。

## 能力上限

这是检索、经验积累与行为调整，不是修改 DeepSeek 模型权重。当前硬件上的可重复验证不能证明“理论极限”，更不能证明主观情感或十年不出错。未来扩展学习词汇需要代码审查与回归；跨模态检索、真正的模型训练、长期盲测和新服务的数据边界应单独验证。允许资源增加，不意味着自动让模型扩大自己的权限。
