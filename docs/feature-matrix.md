# 二十项实现与验收对应

“实现”指以下具体行为；表格不代表接入了未授权账号、任意设备或无边界系统修改。完整测试结果以最后一轮证据为准。

| 方向 | 实现 | 验证与边界 |
|---|---|---|
| 自主目标 | Agency SQLite 持久队列；阅读/研究/整理/反思/实验/提醒；优先级、暂停、恢复、完成、放弃；租约恢复 | test_agency、integration_agency、scope_lifecycle；目标文本不能改权限；每范围最多20个活动目标 |
| 长期兴趣 | 八类种子兴趣；真实讨论、阅读或视频观察作为证据缓慢更新；保留来源和时间 | 每次0.9旧值+0.1新值；标题不等于体验；实际视频笔记与近100条去重 |
| 情绪调节 | 21维有界状态；快情绪、慢关系、昼夜模拟节律；倾听、放松、容纳矛盾、查证、简化表达 | test_emotion_model、test_emotional_quality、真实合成对话；不因不回复扣关系，不诊断用户心理 |
| 人格细节 | 稳定价值与表达阶段、当前交流需求、可学习表达分别保存；允许不同意见 | 私聊与公开群人格隔离；不靠固定台词、舞台动作或亲密词堆砌；具体私人设定不公开 |
| 共同经历 | 已送达交流、真实公开阅读、画面观察、实验和任务进度组成来源事件与小目标记录 | 来源/状态/日期/更正/到期；没有实际回执不增加“共同做过”的事实 |
| 记忆检索 | 现有 Memoria 确认记忆；Agency 本地中文词片、同义词和主题关联检索；来源/新近度加权、去重、冲突替代、解释性到期 | 本地轻量关联检索，不是新增外部嵌入服务，也不保证任意语义等价都召回 |
| 自我学习 | 原文证据、独立作用域、即时明确纠错、七类表达偏好、有效期、修订与撤销；实际送达措辞反馈与版本隔离的效果核对 | test_learning、integration_learning；不能学习新主人、密钥、白名单或核心人格覆盖指令 |
| 群内理解 | 发言人/引用/@/时间绑定；多主题、同人碎片合并；每人一个待处理项的公平队列 | integration_groups、scope_matrix；只回应当前话题；兴趣插话仍需模型高置信判断 |
| 主动交流 | 同一个时钟驱动；真实新进展、未完成事项、阅读发现；允许不发送 | 免打扰23–08、无人回应暂停、价值去重、全局与每范围发送限额；统一回执账本 |
| 后台公开研究 | 公开搜索、实际页面读取、来源笔记；39项明确域名；同范围短期公开缓存 | real service probe、公共检索工具；摘要与全文区分；网站可能限制访问；网页不授予权限 |
| 提醒与待办 | 明确自然语言意图调用目标工具；上海时区、具体时间或相对分钟；调整/取消/完成 | due_reminders直接查询，避免被高优先级目标遮挡；以分钟级时钟和当前QQ限制为准；勿扰期间延后 |
| QQ细节 | 已观察消息表态、本人近期消息撤回、来源卡片、安全生成文件原生上传 | integration_agency、qq_actions；只使用实际消息引用；不确定回执不重试；原生接口能力按SnowLuma实际返回 |
| 表情理解 | 46张审核图的画面标签、类别/关键词检索、近期重复抑制、每范围偏好与冷却 | 现有审核图和实际发送路径；不让模型指定任意文件路径；源码包不带第三方图片 |
| 跨会话媒体 | 有意读取的文件/OCR文字可生成带来源资料；跨范围共享先检查文本、私密标记及全部附件来源 | 文件派生物继承7天期限；不能可靠检查的原图、未知附件继续排除；OCR不保证发现全部视觉隐私 |
| B站私人整理 | 私密分类收藏、稍后再看、实际画面采样与观看回执；长期兴趣与去重视频笔记 | 独立登录域；收藏夹私密属性与实际归属逐次核验；没有音频理解保证；评论/弹幕/公开互动禁用 |
| 资料产出 | 每范围独立目录生成md/txt/csv/json/html笔记、摘要、表格数据、网页草稿、实际实验结果 | 16MB资料配额；网页作为静态资料，不自动发布；代码实验无生产访问 |
| 自主管理 | 自选兴趣、目标、休息、资料来源、5–8h共享活动上限内的时长；有限节奏和表达偏好 | 参数逐项列举；不让模型修改等级、白名单、密钥、系统权限或勿扰时段 |
| 维护能力 | 宿主机确定性巡检、源码/辅助文件校验、服务重启与已验证镜像重建、SQLite验证恢复；模型查看去敏指标与请求检查 | 独立41项故障验收；低风险动作自动执行，未知代码不直接部署；有恢复点、隔离与频率限制 |
| 成本与性能 | 分类/深度规划/工具分预算；后台规划与max主动思考额度分开；本地检索和公开短期缓存；单个浏览/解析重任务 | 五轮稳定性、并发写锁基准、页载入期间健康检查；内存不足/低磁盘/高温/时钟突变暂停可选活动 |
| 可见控制 | 自主状态、目标、来源、实际行动、额度、每范围暂停与等级、群内主动开关、自修复状态开关 | /自主空间、/群内主动、/自修复；不展示内部推理链或其他人的私聊 |

临时附件仅在明确要求理解时下载。原件、提取文本和可识别派生物7天失效；请求时拒绝过期读取，宿主机定期物理清扫。聊天平台已经收到的消息无法靠本地清扫“远程遗忘”。
