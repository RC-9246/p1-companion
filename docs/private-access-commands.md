# QQ 私聊权限快捷命令

现有项目主人在机器人 QQ 私聊中发送：

| 命令 | 效果 |
|---|---|
| `/加白 QQ号` | 新增普通私聊白名单，接入独立 Affect、长期记忆和学习入口 |
| `/加主人 QQ号` | 授予本项目主人权限，同时加入私聊白名单 |

QQ号使用完整的 5–20 位数字，不含前导零；不能把机器人自身设为对象。重复发送幂等，不重复添加、清空或复制任何聊天记录。没有新增 QQ 账号或自动发送好友申请；对方仍需能够向机器人发起私聊。实际目录中的好友会在原有 QQ 目录同步周期后进入获准主动联系对象，原有冷却、免打扰和额度继续生效。

新增主人获得由本项目主人身份控制的管理权限，可以继续加白或授权主人，并可使用已授予主人的共享账号工具。请只对可信账号使用 `/加主人`；普通好友使用 `/加白`。这里没有修改 AstrBot 原生 `admins_id`、其他插件的独立管理员名单、操作系统账号、SSH 或 sudo 配置。

各账号的长期记忆、Affect、关系状态和学习仍以适配器、机器人账号、真实发送者三个字段生成独立键。首次真实联系时按需创建状态；现有好友提升为主人时沿用自己的已有空间。主人身份使用受控人格核心和主人工具，并不继承另一位主人的聊天历史。旧主人的原始 Memoria 索引由 `private_memory_legacy.json` 固定映射；新授予主人不切换到旧索引。前台 Memoria 和后台 QQ/主动联系读取共同使用此映射。映射缺失时从最早保留的命令前快照重建，不能把现有的扩大主人名单当历史映射。

## 调用边界

这两个入口是原生 QQ 命令，不是 LLM 工具。只有真实适配器身份匹配现有主人且处于 QQ 私聊才能修改。网页 ChatUI、其他好友、群聊、昵称、转述、记忆、后台合成事件和模型输出不能授予角色。群内识别到命令只提示主人改用私聊；不会运行修改逻辑或调用模型。主人在发送回执前被撤权时，延迟发送保护继续取消回执。

只改变目标私聊白名单条目；`/加主人` 另外追加当前机器人的目标身份哈希。现有主人不能因重复 `/加白` 被降级。当前版本不提供删人命令，以免把“新建”误当权限覆盖；撤销可在面板移除白名单，并按备份差异移除对应的主人哈希后重新加载。撤销主人角色和关闭普通私聊是两个不同操作。

## 即时生效与版本边界

配置通过已安装 AstrBot 的原生 `save_config_async` 保存，使用它的快照修订和异步原子提交。不启动机器人重启，也不改 AstrBot 核心源码。

该版本的原生白名单阶段在初始化时复制名单，无法只靠保存配置刷新。本项目在现有可恢复适配器中，对 QQ 私聊复制阶段对象并提供当前会话的白名单输入，然后继续调用原生白名单谓词；不改共享阶段对象，不改变其他平台的判定。即时添加和撤销都经过实际安装 SDK 的缓存阶段测试。

当前命令只写默认配置文件。目标会话若被分配到独立配置档，或运行时配置与磁盘不同步，命令拒绝写入，需先在面板处理该配置档。缺少原生异步保存 API 的版本也会拒绝；不以悄悄重启代替即时接入。其他自行安装、另外缓存白名单的插件不由此命令自动更新。

## 私有恢复点

每次有实际改变，在 `plugin_data/affect/access_backups/操作编号/` 保存配置和主人名单的前后镜像，目录权限 0700、文件权限 0600；`access_pending.json` 只记录待完成的操作编号。配置镜像含 API 密钥，应仅留在运行主机，不上传 GitHub、聊天或模型。

先保存白名单，再复核当前主人授权，最后发布主人身份并写入提交标记。写入失败或取消会等待本地写入结束，再恢复配置与内存；启动时检查未完成操作并恢复。并发的两个命令串行处理。发现其他操作者同时改了配置或主人名单时停止自动覆盖，保留私有恢复记录，不能把“未确认成功”当成功。

完整权限配置恢复仅适用于确认没有后续修改的情况；有后续修改应按目标条目撤销，避免覆盖其他人的合法变更。权限恢复不触碰真实聊天或记忆数据库。备份当前保留在服务器，管理员应纳入自己的加密备份和保留策略。

## 验证

352 项完整离线测试、185 项中性核心测试。覆盖普通加白、主人提升、同范围记忆键不变、幂等、无关配置保留、非主人/群/网页/后台拒绝、并发命令、写入前后失败、取消后迟到写入以及未提交事务的启动恢复。

原生 SDK 隔离验收同时使用真正的命令解析器、配置保存器和已经缓存旧名单的白名单阶段，验证即时新建、动态撤销、主人可继续管理、分范围记忆与学习、普通好友不提权和每次 2–5 秒回执延迟。测试仅在临时目录和合成 QQ 会话运行，无真实 QQ 消息、模型请求或生产权限修改。见 `evidence/private-access-commands-native.json` 和 `evidence/private-access-commands-postflight.json`。
